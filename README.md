# Interrogation-of-brain-in-patients-with-severe-COVID-19-
Interrogation of brain in patients with severe COVID-19 using R (PCA, Cluster, UMAP) 

Principle component analysis is performed on the preprocessed data and 100 principal components were identified. Using the first 20 components, shared nearest neighbor clustering was performed. To visualize the results, uniform manifold approximation and projection visualization was employed. Differential expression is calculated based on non-parametric Wilcoxon rank sum test between specified groups. We used Seurat to perform normalization, PCA and UMAP dimensionality reduction and visualization, and to calculated differential gene expression. DAVID was used to carry out gene set enrichment analysis on identified differentially expressed genes.
